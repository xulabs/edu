# Machine Learning for Scientists

Welcome to the **Machine Learning for Scientists** educational track (CMU 02-620). This curriculum explores the statistical, probabilistic, and mathematical foundations of machine learning tailored for scientific and biomedical discovery.

For the complete syllabus, roadmap, and module details, see the **[Tutorial Series Guide](tutorial/README.md)**.

**New to programming and mathematics?** Start with **[From Biology to Machine Learning](tutorial/BiologyToML/README.md)** — a 45-module self-study course written for first-year biology majors. Level 1 (Modules 00–23) builds the prerequisites from scratch (Python, probability, linear algebra, calculus, MLE/MAP) and then teaches the full content of every CMU 02-620 lecture with step-by-step derivations and from-scratch implementations; Level 2 (Modules 24–43) carries the same ideas to current computational-biology research (single-cell and spatial omics, statistical genetics, regulatory genomics, protein language models and structure, generative design, molecular ML, causal inference, trustworthy ML, AI agents); a capstone (44) ties it together. All data are synthetic and generated by code. The topic tutorials below are natural deep dives.
